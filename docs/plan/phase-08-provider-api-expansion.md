# Phase 8 — Broader providers, full API inventory, and optional self-update

Status: in progress. The broader provider preset catalog, deterministic metadata checks, gateway-owned stored/background Response lifecycle, gateway-owned stored Chat Completion lifecycle, bounded gateway-owned OpenAI Files/Uploads, Anthropic Message Batches and OpenAI Responses/Chat Completions/Embeddings/Moderations/Image Generations Batches, bounded native OpenAI Responses web search, bounded native Anthropic JSON/SSE basic web search with public-model stream normalization, and native OpenAI image edit/variation and audio transcription/translation operations are implemented; live certification and larger resource/auth work remain open. Begins after v0.1 unless a specific provider becomes a prerequisite for the user's first deployment.
