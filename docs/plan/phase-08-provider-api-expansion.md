# Phase 8 — Provider expansion, compatibility inventory, and optional self-update

Status: closed for this release. The provider catalog, supported/pending API inventory, deterministic compatibility evidence, bounded gateway-owned resources, and optional signed Linux self-update are implemented. Live provider certification, remote-database certification, and additional vendor resource families are deferred future work rather than release claims. [Plan index](README.md)

This post-stable expansion phase delivered the bounded items below. ADR-051 closes it for the current release without claiming the deferred work.

## Incremental parity evidence — 2026-09-18

- Anthropic `web_search_20260318`, `web_fetch_20260309`, and `web_fetch_20260318` extend the bounded native routes. `response_inclusion` (`full`/`excluded`) and fetch `use_cache` are version-gated, forwarded unchanged, and require distinct public/upstream `web_search_response_inclusion`, `web_fetch_cache_bypass`, and `web_fetch_response_inclusion` capabilities. - One Anthropic web search tool and one web fetch tool may now appear in the same JSON or SSE Message. Both validators run independently, both target eligibility and scope checks apply, and the companion `server_tool_use` count is tolerated while each tool reconciles its own ceiling and cumulative monotonicity. Combined JSON and SSE tests cover dual-count parsing, accounting (`web_search_max_calls`/`web_search_call_count` plus summed response tool calls), public-model normalization, and missing-scope rejection before dispatch; Message Batch rejection remains.
- Anthropic prompt caching may now be combined with hosted web search or fetch, including a `cache_control` breakpoint on the tool definition. A focused JSON test covers forwarding, public-model normalization, and simultaneous cache-creation/cache-read counters with web-search usage and call accounting on a model that publishes both `prompt_cache` and both web-tool capability sets.
- Local verification passed on 2026-09-18: formatting, vet, staticcheck, the complete Go suite, dashboard production typecheck, all 73 frontend tests, and packaged-binary smoke. The full gateway `-race` suite passes with an extended timeout; it takes ~650s at the pre-change baseline and ~632s with this change, both above Go's default 10-minute per-binary limit on this machine, so selected-package race coverage was used for the affected packages and the full suite was re-run with `-timeout 900s`. No credentialed live Anthropic request was run.
