Cross-provider generation covers the shared documented subset. Anthropic client streaming remains native-target only because input usage is required in the first Anthropic event. Native Anthropic Messages supports bounded ephemeral prompt-cache controls with explicit capability and accounting gates; cache directives are not translated. It also supports one direct JSON or SSE `web_search_20250305` tool with a 1–4 use ceiling, public/upstream `chat` and `web_search`, the built-in `anthropic` preset, and `messages:web_search`; native search blocks, citations, continuation state, SSE frames, and reported calls are preserved without translation or post-dispatch fallback. Gateway-owned Anthropic Message Batches run one to four ordinary Messages locally with creating-key ownership, a 16 MiB submission limit, a 24-hour processing expiry, and ordinary routing/accounting prices; the whole batch and its JSONL results are deleted 29 days after creation. Gateway-owned OpenAI Files store creating-key-owned Batch JSONL input for at most 30 days and expose the five stable official SDK operations. Gateway-owned OpenAI Responses Batches run one to four non-streaming requests locally with creating-key ownership, a 24-hour processing window, ordinary routing/accounting prices, and separate success/error output Files; they do not claim OpenAI's provider Batch discount, limits, or rate pool. General Uploads, Vector Stores, other file purposes, additional Batch endpoints, and provider-owned Batches remain separate contracts. Responses web search requires an OpenAI-adapter target using the built-in `openai` preset, explicit call/output ceilings, public/upstream capability, and a separate key scope. Search-call cost remains unknown for both web-search contracts, so lowest-cost, free-only, and spend policies reject them before dispatch. Embeddings, moderations, and token counting require native capable targets. Other hosted tools, opaque reasoning blocks, realtime, other cache APIs, and provider-owned conversations are unsupported until explicitly implemented and tested.

No paid-provider certification is claimed. CI uses deterministic local providers; live provider results must be added here with date, provider API version, model, and exact operations.
