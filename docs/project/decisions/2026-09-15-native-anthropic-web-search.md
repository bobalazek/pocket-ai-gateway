# 2026-09-15 — Bounded native Anthropic basic web search

ID: ADR-020 · Status: accepted · Source: user-approved Phase 8 scope with delegated technical contract

**Context.** Anthropic Messages can invoke provider-hosted web search. Search calls have separate provider billing, return opaque encrypted result state for later turns, and can pause an agentic turn. Translating the tool or retrying it after dispatch could change citations or duplicate billable work. The gateway does not yet have a versioned Anthropic search-price contract.

**Decision.** Pocket AI Gateway accepts one basic `web_search_20250305` tool alongside ordinary application tools only for non-streaming JSON `POST /api/anthropic/v1/messages` requests. The tool name is `web_search`, `max_uses` is a required integer from 1 through 4, and `allowed_callers`, when present, must be exactly `["direct"]`. Allowed- and blocked-domain lists are mutually exclusive and limited to 100 entries; approximate user location is preserved. Prompt caching cannot be combined with web search. Dynamic-filtering versions and deferred or indirect invocation are unsupported.

The public and upstream models must both publish `chat` and `web_search`, and the selected target must use the Anthropic adapter with the built-in `anthropic` preset. The key needs both `chat:generate` and `messages:web_search`. Eligible ordered, weighted, or latency routing may select a target before dispatch. Web-search requests never translate or fall back after dispatch and reject lowest-cost, free-only, and spend policies before dispatch. Native `server_tool_use`, `web_search_tool_result`, encrypted result content, citations, `pause_turn`, embedded tool-result errors, token usage, and `usage.server_tool_use.web_search_requests` remain in the Anthropic response. Reported successful searches are recorded separately from tokens; their cost remains unknown.

**Consequences.** Operators opt in through provider-model capability, public-model capability, user/key grants, and key scope. Clients must preserve encrypted result content when continuing a search turn. Search-result errors remain successful HTTP Messages responses, as defined by Anthropic, and unsuccessful searches are not counted as billed calls. Streaming, Message Batches, newer search versions, translated targets, live-provider certification, and hard-coded provider search prices remain separate work.
