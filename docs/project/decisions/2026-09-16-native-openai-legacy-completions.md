# 2026-09-16 — Native OpenAI legacy Completions and gateway-owned Batches

ID: ADR-033 · Status: accepted · Source: delegated technical choice extending the user-approved Phase 8 compatibility scope and ADR-024 through ADR-031

**Context.** OpenAI's legacy Completions endpoint has request, response, streaming, prompt-array, token-ID, log-probability, and candidate-selection semantics that cannot be translated faithfully to Chat, Responses, Anthropic Messages, or Gemini generation. OpenAI Batch also accepts `/v1/completions`, while the gateway's local Batch worker is designed to execute every item through its ordinary endpoint path.

**Decision.** Add native JSON and SSE `POST /api/openai/v1/completions` with a distinct `completions` model capability and `completions:generate` key scope. Both public and upstream models must publish the capability, and the selected target must use the OpenAI or OpenAI-compatible adapter with preset support for `completions`; no cross-protocol translation is attempted. Request bodies are limited to 16 MiB and strictly validate the official prompt shapes, fields, types, ranges, and `n`/`best_of`/stream relationships before dispatch. JSON responses and individual SSE events are limited to 16 MiB, preserve native choices and log probabilities, and expose the requested public model alias. Admission multiplies the per-candidate output reservation by prompt cardinality and the greater of `n` and `best_of` with checked arithmetic; a request without positive `max_tokens` remains unbounded for token, output-token, and spend policies.

Extend the gateway-owned OpenAI Batch queue to accept one to four non-streaming `/v1/completions` items for one public model. Creation requires `batches:manage` and `completions:generate`; each item rechecks current grants and executes through the ordinary Completions routing, admission, accounting, pricing, and validation path. Successful JSONL output preserves the Completion body with the public model alias, and provider-reported prompt/completion usage contributes to aggregate Batch usage.

**Consequences.** The existing encrypted input/results, 24-hour processing deadline, cancellation/recovery behavior, 30-day Batch retention, optional shorter output-File retention, and separate success/error Files apply. The gateway does not translate legacy prompts, claim support from presets that do not advertise the operation, or use OpenAI's provider-owned Batch service, discount, rate pool, or larger ceilings. Video and provider-owned Batch execution remain separate contracts.
