# 2026-09-17 — Asynchronous media and scripted provider adapters

ID: ADR-052 · Status: accepted · Source: user decision with delegated technical implementation

**Context.** Image, audio, and video providers do not share one synchronous wire contract. Together exposes both OpenAI-compatible media endpoints and asynchronous video jobs. Replicate exposes a stable prediction lifecycle while each model defines its own input and output schema. Operators also need to connect APIs that cannot be represented by a base URL alone. The product must remain one Go executable.

**Decision.** Pocket AI Gateway owns a provider-neutral persistent media-job lifecycle for create, inspect, list, and cancel operations. Native provider drivers translate that lifecycle to vendor APIs, beginning with Replicate and Together. Polling retries transient network, timeout, rate-limit, and server failures with bounded backoff; permanent or exhausted failures terminate the job. A restart after dispatch but before the provider ID is stored produces `interrupted_unknown` because exactly-once submission cannot be guaranteed. Custom provider connections may run JavaScript request and response transforms inside a pure-Go embedded JavaScript VM. Every invocation receives JSON data and returns JSON data; scripts receive no filesystem, process, module-loader, timer, or direct network APIs. The gateway retains authority over HTTP destinations, credentials, redirects, timeouts, body limits, ownership, and auditing.

The embedded runtime is Goja. Bun and Deno remain external application runtimes and are not bundled. A fresh VM executes each invocation so state cannot cross requests. Source, stack, input, output, and wall time are limited. Goja shares the server heap and provides no hard per-invocation heap ceiling, so adapter source is trusted owner/admin configuration rather than untrusted plugin code. JavaScript augments a declared HTTP adapter; it cannot create arbitrary network requests or bypass gateway policy.

**Consequences.** Media jobs survive restarts and expose explicit provider and terminal state, including an honest unknown state for the narrow submission crash window. Provider-specific inputs remain JSON rather than being forced into an inaccurate universal video schema. Scripts are administrator-managed code and must be reviewed before activation, interrupted on timeout, size-limited, and audited without logging source or secrets. Streaming and bidirectional realtime transports remain separate from asynchronous media jobs because they have different connection and accounting lifecycles.
