# 2026-09-18 — Anthropic combined web search and fetch

ID: ADR-056 · Status: accepted · Source: delegated technical choice extending the user-approved API compatibility scope

**Context.** ADR-054 and ADR-055 added the versioned Anthropic web search and fetch tools but kept them mutually exclusive, rejecting a request that contained both. Anthropic documents a combined search-and-fetch workflow: when both tools are enabled, the model can search to locate a page and then fetch it. The gateway already preserved both native result shapes, so the restriction was a gateway policy rather than an upstream limitation.

**Decision.** Allow one `web_search` tool and one `web_fetch` tool in the same JSON or SSE Message. Each tool keeps its own accepted versions, field validation, 1–4 `max_uses` ceiling, capability chain, and scope. The request must satisfy both public and upstream capability sets, both `chat:generate` scopes (`messages:web_search` and `messages:web_fetch`), and both target eligibility checks. A combined response may report `web_search_requests`, `web_fetch_requests`, and, for dynamic callers, `code_execution_requests` in the same `server_tool_use` object; each tool's count is validated against its own ceiling and must be present and non-decreasing, and the companion count is tolerated when its own parser reconciles it. The public model alias is normalized for non-stream JSON as well as `message_start`, matching fetch. Combined requests inherit the search contract's unknown provider call price, so spend, free-only, and lowest-cost policies reject them. Prompt caching, translation, deferred tool loading, post-dispatch fallback, and local Message Batches remain rejected.

**Consequences.** No new execution runtime or provider fee is introduced; both tools are provider-hosted and forwarded unchanged. Search calls continue to occupy the single `web_search_max_calls`/`web_search_call_count` accounting columns while fetch calls are counted in the response tool-call total, so a combined request reports each tool's activity separately without a schema change. This decision extends ADR-055.
