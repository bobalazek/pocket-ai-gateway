# 2026-09-18 — Anthropic prompt caching with hosted web tools

ID: ADR-057 · Status: accepted · Source: delegated technical choice extending the user-approved API compatibility scope

**Context.** The native Anthropic prompt-caching contract already accepts `cache_control` on tool definitions, and the web search and fetch contracts already accept a `cache_control` field on their tool. Anchoring decisions ADR-020 and ADR-032 nevertheless rejected prompt caching in the same request as a hosted web tool, so combined use was a gateway policy rather than an upstream limitation. Anthropic documents caching tool definitions and notes that toggling web search invalidates the system and message caches but not the tools cache.

**Decision.** Allow prompt caching and one hosted web tool, including a combined search-and-fetch request, in the same native Anthropic Message. The request keeps the bounded `{ "type": "ephemeral", "ttl": "5m" | "1h" }` controls, the four-breakpoint limit, and the TTL-order rule; a breakpoint on the web tool definition counts toward that same limit. Public and upstream models must still publish `prompt_cache`, and both web-tool capability sets and scopes still apply. Cache counters and web-tool usage are settled together: `cache_creation_input_tokens`, `cache_read_input_tokens`, and the five-minute/one-hour creation counters are recorded alongside `server_tool_use`, so a combined attempt keeps both signals. Because positive cache creation remains unknown until cache rates are versioned, and search-call cost is unknown, spend policies, free-only routes, and lowest-cost routing still reject the request before dispatch. Translation, deferred tool loading, post-dispatch fallback, and local Message Batches for fetch remain rejected.

**Consequences.** No new provider fee or gateway state is introduced; the existing prompt-cache and web-tool validation and accounting paths compose. Operators opt in through the same provider, model, grant, and scope controls, and cache content is still never persisted. This decision extends ADR-020, ADR-032, ADR-054, ADR-055, and ADR-056.
