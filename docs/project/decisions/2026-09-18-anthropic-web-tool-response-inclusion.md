# 2026-09-18 — Anthropic web-tool response inclusion and cache bypass

ID: ADR-055 · Status: accepted · Source: delegated technical choice extending the user-approved API compatibility scope

**Context.** ADR-054 added Anthropic's `web_search_20260209` and `web_fetch_20260209` dynamic filtering but left the later versions unsupported. Anthropic now documents `web_search_20260318`, which adds response-inclusion control to dynamic search; `web_fetch_20260309`, which adds `use_cache` cache bypass to dynamic fetch; and `web_fetch_20260318`, which adds response inclusion on top of cache bypass. These fields change provider behavior without adding a new execution runtime or a new provider charge, so the gateway must either forward them faithfully or keep rejecting them.

**Decision.** Accept these versions wherever the basic and 20260209 versions are already accepted, keeping the required 1–4 `max_uses` ceiling, every existing scope, routing, combination, and no-fallback rule, and the version-aware caller defaults. On `web_search_20260318` and `web_fetch_20260318`, `response_inclusion` is optional and must be `full` or `excluded`; on `web_fetch_20260309` and `web_fetch_20260318`, `use_cache` is optional and must be boolean. Both fields are rejected on earlier versions. The tool wire form is forwarded unchanged. Because these features are intrinsic to the tool version rather than to how it is invoked, selecting one of these versions additionally requires the corresponding public/upstream capability: `web_search_response_inclusion` or `web_fetch_response_inclusion` for the 20260318 response-inclusion versions, and `web_fetch_cache_bypass` for the 20260309/20260318 cache-bypass versions. This differs from `web_search_dynamic`/`web_fetch_dynamic`, which track whether a request actually invokes through code execution. Capability publication enforces the chain `web_search_dynamic` → `web_search_response_inclusion` and `web_fetch_dynamic` → `web_fetch_cache_bypass` → `web_fetch_response_inclusion` so a model cannot advertise a later behavior without its predecessors.

**Consequences.** The gateway forwards the new fields unchanged and continues to preserve native result, caller, and usage shapes; Anthropic remains responsible for producing or omitting nested result blocks and for cache behavior, and token or search/fetch accounting stays on the existing path. Cache bypass and response inclusion therefore add no gateway-side state or provider fee. Standalone code execution, computer/browser use, and connectors remain separate contracts. This decision extends ADR-054.
