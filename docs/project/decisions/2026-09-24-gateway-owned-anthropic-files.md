# 2026-09-24 — Gateway-owned Anthropic Files

ID: ADR-059 · Status: accepted · Source: delegated technical choice for requested native file compatibility

**Context.** Anthropic's current Files API is generally available and uses `{data,next_page}` pagination without the old `files-api-2025-04-14` beta header. Provider file IDs belong to an upstream workspace; forwarding uploads or accepting arbitrary provider IDs would let keys sharing a connection reach each other's files. The single-binary gateway already has encrypted local resources, creating-key ownership, retained-resource ceilings, and paired-store backups.

**Decision.** Serve a bounded Anthropic Files slice under `/api/anthropic/v1/files`: upload, list, metadata, delete, and the documented 400 response for downloading an uploaded file. Keep bytes encrypted in the system store and owned by the creating gateway key under `files:manage`; no upload is sent to a provider. Accept PDF, UTF-8 text, JPEG, PNG, GIF, and WebP up to 8 MiB. Files expire after 30 days by default or 1–90 days when requested. A same-key `file_id` in a Messages or count-tokens document/image block, including nested `tool_result.content`, is resolved before routing and expanded to the appropriate native inline source (PDF base64, text/plain text, image base64). Such requests require a native Anthropic target, allow at most 32 references, must fit 16 MiB after expansion, and count expanded bytes toward input and body-size admission. Unknown, expired, foreign-key, mismatched, direct provider `file_id`, and unsupported references fail before dispatch. Legacy beta Files response shapes are rejected explicitly.

**Consequences.** The current GA SDK's basic Files lifecycle can use gateway URLs without exposing shared upstream workspace files. This is local gateway storage, not upstream Files persistence: the gateway cannot download generated provider files or support `container_upload`, 500 MB uploads, `ids[]` listing, the provider's no-expiry default, or 101–1000 item pages. Same-key file references have ordinary Messages token charges. The master key must accompany paired database backups. [Anthropic Files guide](https://platform.claude.com/docs/en/build-with-claude/files), [HTTP upload](https://platform.claude.com/docs/en/api/http/files/upload), [list](https://platform.claude.com/docs/en/api/http/files/list), and [Messages document sources](https://platform.claude.com/docs/en/api/http/messages) define the upstream shapes.
